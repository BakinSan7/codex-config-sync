# Codex Config Sync

**Один проверяемый профиль для Codex и Claude Code на Windows и macOS: общие инструкции, переносимая память, выбранные настройки и каталог skills, из которого вы выбираете нужное при установке.**

[English version](README.md)

> [!IMPORTANT]
> Неофициальный проект сообщества. Он не связан с OpenAI и Anthropic и не одобрен ими.

## Зачем это нужно

Если копировать `~/.codex` или `~/.claude` между компьютерами, вместе с настройками уедут пароли, разрешения, плагины, кэши, пути конкретного устройства и история чатов. Codex Config Sync хранит в Git небольшой явный профиль и ставит на каждое устройство независимые копии:

- один файл инструкций превращается в `~/.codex/AGENTS.md` и `~/.claude/CLAUDE.md`;
- skills предлагаются каталогом с короткими пояснениями, и ставятся только выбранные;
- каждое изменение показывается коротким деревом, а по каждому пункту решаете вы: принять, оставить своё, пропустить, убрать или объединить;
- решения запоминаются на устройстве, а оставленная или объединённая вами версия никогда не заменяется молча;
- записи идут через журнал, их можно откатить, а ссылки, junction и reparse point скрипты отвергают;
- настройки конкретного устройства (модель, глубина рассуждений, разрешения, hooks, команды MCP, плагины, учётные данные) скрипты отказываются переносить.

## Что нужно

- Windows 10/11 с PowerShell или поддерживаемая версия macOS;
- Python 3.11 или новее и Git;
- Codex и/или Claude Code, чтобы профилем пользоваться. Самим скриптам хватает стандартной библиотеки Python.

## Быстрый старт

Склонируйте репозиторий и запустите первую установку. Установщик покажет каталог skills и спросит, какие поставить.

macOS:

```bash
git clone https://github.com/BakinSan7/codex-config-sync.git ~/codex-config-sync
cd ~/codex-config-sync
./codex-sync.sh bootstrap
```

Windows PowerShell:

```powershell
git clone https://github.com/BakinSan7/codex-config-sync.git $HOME\codex-config-sync
cd $HOME\codex-config-sync
.\codex-sync.ps1 bootstrap
```

Если установщик запущен без терминала (например, его запускает агент), выбор передаётся явно: `--skills recommended`, `--skills all`, `--skills none` или номера и имена из каталога, например `--skills 1,5,fact-check-post`. Посмотреть список заранее можно командой `catalog`.

Чтобы хранить свои инструкции и память, нажмите на GitHub **Use this template**, сделайте новый репозиторий **приватным**, впишите его `owner/name` в поле `repository` файла `manifests/profile.json` и клонируйте уже его. Личную конфигурацию в публичный форк не кладите.

## Обычная работа

| Команда | Что делает | Что меняет |
| --- | --- | --- |
| `catalog` | Показывает каталог: ★ рекомендуемые, ✓ уже установленные | Ничего |
| `bootstrap` | Первая установка: спрашивает про skills, ставит новое, проверяет | Файлы профиля |
| `preview` | Получает репозиторий и показывает деревом, что изменится | Только локальный план |
| `apply --plan <план> [--decisions <файл>] [--accept-safe]` | Применяет проверенный план с вашими решениями | Файлы профиля |
| `verify` | Проверяет, что установленное совпадает с выбором | Ничего |
| `detail --plan <план> --id <пункт>` | Показывает точный текст изменения | Ничего |
| `rollback --id <транзакция>` | Возвращает состояние до применения | Файлы профиля |
| `scan [--public-audit]` | Ищет секреты, опасные файлы и личные пути | Ничего |
| `publish "сообщение" <файлы>` | После тестов и проверки публикует только перечисленные файлы | Ваш репозиторий |

Чтобы добавить skill позже: `preview --skills fact-check-post`, затем `apply --plan <новый план> --accept-safe`. Подробности — [Синхронизация](docs/SYNC.md).

## Что остаётся на устройстве

- модель по умолчанию, глубина рассуждений и доступность моделей;
- разрешения, песочница, подтверждения и системные разрешения;
- hooks, команды строки состояния, команды MCP и состояние плагинов;
- пароли, токены, cookies, ключи и данные менеджера паролей;
- чаты, сессии, автопамять, логи, кэши и резервные копии;
- настройки интерфейса устройства: шрифты, размер окна, горячие клавиши.

Правила только для одного устройства с Claude Code кладите в `~/.claude/rules/*.md`: Claude Code загружает их вместе с `CLAUDE.md`. Подробнее — [Переносимость](docs/PORTABILITY.md).

## Ограничения

- Сканер — дополнительная страховка, а не доказательство, что в файлах нет личных данных.
- Объединение — это целый документ, который вы утверждаете; автоматически текст не сливается.
- Модель угроз не защищает от злонамеренного локального администратора.
- Настройки Codex и Claude Code меняются. Перед добавлением новых ключей сверяйтесь с официальной документацией.
