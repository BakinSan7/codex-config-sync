# Claude Code personal skills

Put complete Claude Code skills you own here, one directory per skill with a
`SKILL.md` marker file, then list each directory name in the `claude_skills`
table of `manifests/portable-files.json` under `common`, `windows`, or
`macos`.

Listed skills install to `$CLAUDE_HOME/skills/` (`~/.claude/skills/` by
default).

Only add skills you own or may legally redistribute inside your private
repository. Third-party skills stay outside the sync by design: verify their
license, source revision, contents, and dependencies before installing them
locally by hand.
